# Release notes

De naslag voor wie bouwt: volledig, met de waarom's. Wat collega's in de tool zien staat in
`RELEASE-NOTES-KORT.md`. Elke PR die gedrag, schema of afspraken verandert, krijgt hier een eigen
versiekop met de rubrieken Toegevoegd, Gewijzigd, Gerepareerd, Bewijs en, als er iets met de hand
moet gebeuren, Let op bij bijwerken.

## v0.01

Het project is aangemaakt uit het template.

### Toegevoegd

- Het skelet uit het template: toolchain met vastgepinde versies, huisregels, contrastcheck, een
  neutraal thema in twee modi, de layout met zelf gehoste fonts, en de documenten voor
  "Over de tool".

### Bewijs

- Typecheck, lint en huisregels schoon; de unittests groen; de build schoon; het contrast haalt de
  norm in beide modi.

### Let op bij bijwerken

- Loop `docs/handleiding/01-start-hier.md` door voor de accounts en de variabelen.
